# Mi Proyecto Web con Git

Práctica del módulo Git y GitHub aplicada a mi análisis de ventas. La página `index.html` presenta el gráfico de resultados del proyecto.

## Archivos

- `index.html`: página web inicial.
- `grafico_resultado.png`: gráfico de resultados.
- `proyecto.py`, `proyecto_modulo3.py` y `proyecto.ipynb`: código del análisis.

El conjunto de datos utilizado en Python no se publica aquí porque incluye información de clientes. Para ejecutar el análisis localmente, el archivo de datos debe estar en la misma carpeta con el nombre `dataset_analisis.csv`.

La rama `feature/estilos` añade el archivo CSS. La rama `feature/scripts` añade un archivo JavaScript. Ambas nacen de `main` y muestran cambios independientes.
